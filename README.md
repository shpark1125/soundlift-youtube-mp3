# Soundlift

유튜브 링크에서 가장 좋은 가용 오디오 스트림을 받아 320 kbps MP3로 인코딩하는 웹사이트입니다.

## 실행

Windows에서 `run.ps1`을 PowerShell로 실행하세요. Python 3.10 이상이 필요합니다. 처음 실행할 때 `yt-dlp`와 FFmpeg 바이너리를 포함한 `imageio-ffmpeg`가 설치됩니다. 사이트는 `http://localhost:3000`에서 열립니다.

변환 파일은 `downloads/`에 저장됩니다. 영상 확인 후 **MP3 다운로드**를 누르면 변환이 끝나는 즉시 브라우저 다운로드가 자동으로 시작됩니다.

원본 음원보다 좋은 소리를 만들 수는 없습니다. 320 kbps는 출력 MP3의 비트레이트입니다. 본인이 권리를 가진 영상에 사용하세요.

## Vercel 배포

`app.py`는 Vercel의 FastAPI 진입점입니다. 변환은 서버리스 함수의 단일 요청에서 수행하고, 완성된 MP3를 스트리밍으로 브라우저에 전달합니다. 작업 상태나 파일을 서버에 영구 저장하지 않습니다. `vercel --prod` 또는 연결된 Git 저장소로 배포할 수 있습니다.

온라인 버전은 함수 실행 시간에 맞춰 영상 길이를 30분으로 제한합니다. 클라우드의 YouTube 접속 제한이나 함수 실행 시간 초과로 일부 영상은 변환되지 않을 수 있습니다. 긴 영상은 로컬 버전을 사용하세요.
