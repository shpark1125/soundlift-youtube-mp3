# Soundlift

유튜브 링크에서 가장 좋은 가용 오디오 스트림을 받아 320 kbps MP3로 인코딩하는 로컬 웹사이트입니다.

## 실행

Windows에서 `run.ps1`을 PowerShell로 실행하세요. Python 3.10 이상이 필요합니다. 처음 실행할 때 `yt-dlp`와 FFmpeg 바이너리를 포함한 `imageio-ffmpeg`가 설치됩니다. 사이트는 `http://localhost:3000`에서 열립니다.

변환 파일은 `downloads/`에 저장됩니다. 영상 확인 후 **MP3 다운로드**를 누르면 변환이 끝나는 즉시 브라우저 다운로드가 자동으로 시작됩니다.

원본 음원보다 좋은 소리를 만들 수는 없습니다. 320 kbps는 출력 MP3의 비트레이트입니다. 본인이 권리를 가진 영상에 사용하세요.
